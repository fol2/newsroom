# Increment 10B1 bounded scope

`newsroom.increment10.scope.FROZEN_SCOPE` derives all policy bytes from the owner-approved plan. It fixes the exact cohort, prospective window, rights and sensitive-content treatment, reviewer roles, default-deny credentials and egress, gross budgets, protected-artifact lifecycle, production differences, early-stop precedence, containment and rollback.

The object is recursively immutable. A material change requires a distinct content-addressed owner plan. It grants no deployment or runtime authority.
