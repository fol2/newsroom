retrievers and two fixed relational-authority ports, then retains one common

`GRAG-034` to 5C. `GRAG-035` and `TRI-022` remain owned by the composed

## Exact receipt identities

Each call retains four separately attributable identities:

- 5C1 authorization receipt digest and deterministic decision UUID;
- route execution request and receipt digest;
- upstream Increment 5B branch or fixed authority receipt digest when executed;
- common dispatch request and receipt digest.

The common dispatcher registry digest binds the exact six-tool route map and the
four-port branch plus two-port authority registry digests. Replay cannot swap a
route, port, child receipt or upstream receipt without a digest or semantic
binding failure.

## Authority boundary

The two relational tools are current read operations, not new editorial
authority. Their SQLite journals are non-authoritative audit stores. The
collision tool returns current collision and permitted metadata but no factual
content bytes. The impact tool returns bounded lineage metadata but creates no
source, revision, signal, lead, hypothesis, Candidate or handoff.

Every tool and common receipt fixes `authority_effect=NONE`, zero external work,
no qualification authority and no production activation.

## Deferred ownership

5C2 does not deliver:

- exact-first multi-tool orchestration;
- deterministic cross-tool ranking;
- dependency-root deduplication;
- authoritative content hydration into a complete Retrieval Context;
- request-level projection metadata for a composed response;
- a current collision receipt attached to that composed response;
- Hypothesis or Candidate effects;
- evaluation qualification, security admission, credentials, egress,
  publication or activation.

The first six items remain 5D/#253, including `GRAG-035` and `TRI-022`.
Cross-request Hypothesis/Candidate/Handoff effects remain Increment 6/#146.
Full evaluation, operations, security and Operational Admission remain
Increment 8/#148.

## Completion gate

The 5C2 leaf uses Tier S because it includes actual authority and graph-backed
reads. Completion requires:

- focused six-tool and boundary tests;
- complete deterministic CI once on the exact final head;
- only affected Authority and actual-Neo4j service lanes;
- source integrity and exact file inventory;
- one exact-head substantive review;
- zero unresolved P1/material-P2 findings; and
- zero unresolved review threads.

After the leaf merges, parent #252 receives one aggregate Tier-M run over the
accepted main head. That parent gate is not duplicated inside each 5C child.
